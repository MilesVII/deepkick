Fetching
Synchronised lyrics are stored as LRC text in the same tag; most players show them as plain text, some can follow along.
Old Windows taggers wrote Cyrillic (CP1251) text into tags labelled Latin-1, which players show as Êîòÿòà. With this on, such tags are rewritten properly whenever a file is processed.

About
DeepKick Lyrics
Successor of Seventh Lyrics Manager. Downloads lyrics and writes them into the USLT frame of MP3 files and the LYRICS comment of FLAC files.
Lyrics are provided by LRCLIB and, optionally, lyrics.ovh.
